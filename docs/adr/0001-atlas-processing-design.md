# ADR 0001：序列帧图集裁剪工具的初版设计

- 状态：Accepted
- 确认日期：2026-10-14，Asia/Shanghai
- 来源：用户通过 grill-me / grilling 逐轮确认，最终确认保存方案。
- 本轮交付：确认并保存需求；后续开发可运行的 Windows EXE。

## 目标与保证范围

处理规则网格的透明序列帧图集，减少每帧的空白区域，输出每帧为正方形、原行列排列不变的图集。

每张图集独立计算一个统一裁剪区域。所有帧采用相同的帧内裁剪坐标、平移和输出尺寸，保留原动画中的运动，不逐帧居中或单独缩放。

“1:1”指每一帧宽高相等，同时保持原始几何尺度。原图集为4列×3行时，输出整图仍为4:3。严格模式保留解码后的原像素；显式启用重采样时允许插值改变像素值，几何尺度仍保持不变。

默认紧凑裁剪允许整段动画相对画布中心发生统一偏移。“保留原画布中心”选项用于避免该偏移。输出尺寸改变后，外部播放器需要保持同一像素显示比例，才能保持主体显示大小；PNG不记录播放帧率或通用播放器锚点。

输出尺寸不保证一定缩小：原内容已贴满格、额外留边或原帧为矩形时，输出可能持平或变大。

## 输入、界面与交付

- Windows 10/11 x64，提供可双击的窗口EXE；离线运行，无需用户另装Python等运行环境。
- 用户选择输入文件夹和输出文件夹，扫描文件列表，再预览和批量导出。
- 仅处理有透明信息的PNG，统一解码为RGBA；不包含指定背景色抠除功能。无透明信息的PNG及其他格式不处理并说明原因。
- “包含子文件夹”默认关闭；开启后递归扫描，输出保留源相对目录结构。
- 默认5列×5行。每张图片可单独改网格，也可多选统一修改；不自动猜测并套用网格。
- 列数、行数为正整数；处理前显示尺寸、网格、模式和可处理/跳过原因。
- 阈值、留边、保留原中心和采样模式由界面明确显示。预览与导出使用相同参数。
- 原图与结果同步播放，共享像素显示比例，不分别拉伸填满面板；支持暂停、逐帧查看和调整预览帧率。
- 默认从左到右、从上到下播放全部格子。预览帧率不写入PNG；不删除空帧、不改变输出帧序。

## 参数默认值

| 参数 | 默认值 | 说明 |
|---|---|---|
| 网格 | 5列×5行 | 可逐张或多选修改 |
| 保留原画布中心 | 关闭 | 开启时使用围绕原帧中心的统一正方形 |
| 每边留边 | 2像素 | 可调非负整数；0为无额外留边 |
| alpha阈值 | 0 | alpha大于阈值才扩大有效包围盒 |
| 采样模式 | 严格 | 需要插值的情况跳过；可显式切换到重采样 |
| 包含子文件夹 | 关闭 | 开启后保留相对目录结构 |

阈值仅参与裁剪范围判定，不清除裁剪区域内低于或等于阈值的像素。超出最终裁剪区域的像素随裁剪舍弃。默认alpha>0保留所有半透明阴影和特效；alpha=0的隐藏RGB不算有效内容。

留边是对有效包围盒的扩展。扩展区域仍在源帧内时保留原像素；扩展到源帧外时补透明。不因“留边”而清除已有的微弱半透明像素。

## 严格模式算法

### 1. 校验与拆格

源图宽高为A、B，网格为C列、R行。严格模式要求A能被C整除，B能被R整除；每帧尺寸W=A/C、H=B/R。

将每个格子转换到同一个帧内坐标系。所有包围盒都在帧内计算，不能对整张图集直接求一个包围盒。

### 2. 有效范围与并集

对每帧按alpha>阈值求包围盒，采用左上包含、右下不包含的边界。全透明帧不参与并集，但保留其格子和帧序。

共同包围盒记为(L,T,U,V)：左、上取各帧最小值，右、下取各帧最大值。若全部帧都没有有效像素，跳过整图并报告。

### 3. 默认紧凑正方形

设有效宽w=U-L、高h=V-T，留边p：

```text
core = max(w, h)
S = core + 2*p
cropLeft = L - p - floor((core - w)/2)
cropTop  = T - p - floor((core - h)/2)
```

对所有帧共用(cropLeft,cropTop,S,S)。不能因某帧内容不同而调整该帧的裁剪起点。短边扩展差为奇数时，剩余1像素放在右侧或下侧，保持确定的整数坐标。

### 4. 保留原画布中心

开启此选项时，以原帧中心(W/2,H/2)为输出画布中心，并容纳共同包围盒及留边。

整数像素平移要求W、H、S同奇偶。W、H同奇偶时：

```text
S = max(W-2*L, 2*U-W, H-2*T, 2*V-H) + 2*p
cropLeft = (W-S)/2
cropTop  = (H-S)/2
```

W、H一奇一偶时，严格模式跳过并提示：可关闭保留中心，或显式启用重采样进行半像素对齐。不默许中心误差。

### 5. 复制与重排

建立S×S的透明RGBA画布，将统一裁剪区域与当前源帧相交的部分逐像素复制；源帧外补透明，不借用相邻帧像素。严格模式不插值、不缩放、不清理裁剪范围内的颜色或alpha。

按原C列×R行重排，输出总尺寸为(C*S)×(R*S)。所有帧的坐标变换一致：输出坐标=原帧内坐标−统一裁剪起点。

## 显式重采样模式

- 用户主动切换；严格模式不会静默回退到此模式。
- 用源图原始等分网格的连续坐标定义每帧，避免把409.6等格宽独立取整后产生起点偏差。
- 保持原始几何尺度，只为非整数格线、裁剪起点或中心进行亚像素对齐；不把整个图集先缩放到能整除的尺寸。
- 各帧采用一致的帧内输出坐标、采样尺度和插值方法，生成整数边长的公共正方形画布。
- 插值处理须考虑alpha，避免完全透明像素中的隐藏RGB污染半透明边缘；采样限制在当前格内，不能吸入相邻帧内容。
- 用实际采样规则计算/验证共同有效范围，确保默认阈值下的有效内容不会因插值支持范围而意外丢失。
- 预览明确标示重采样模式；颜色、alpha及边缘可能变化，不能承诺与原PNG逐像素一致。这里保留的是几何尺度和帧间位置关系。

## 文件与异常处理

- 输出RGBA PNG，保留原文件名。目标已存在时加数字序号，不覆盖已有结果。
- 输出目录不能与输入目录相同或位于其内部；比较规范化路径，避免递归处理自己的输出。
- 保留源文件。批量时一张图失败不影响其他图片；显示进度，结束提供成功、跳过、失败及具体原因清单。
- 文件损坏、无透明信息、网格不合法、严格模式非整除、中心无法整数对齐等情况分别报告。
- 个别全透明帧原位保留；整张图在当前阈值下没有有效内容则跳过。
- 有效内容触及原格边界时警告；只保留已有信息，不推断或修复源图已截掉的内容。
- 逐图处理，避免一次将整个目录的解码图像和结果同时驻留内存。

## 开发验收

1. 在不安装Python的目标Windows环境中，双击EXE可启动、扫描、预览和导出；断网也能完成处理。
2. 通过文件列表设置样例真实网格后，严格模式可处理8张并明确跳过23张；每张图片原因清楚，批量继续。
3. 上表3张样例在默认参数下产生准确尺寸；其余整数网格样例满足同一算法。
4. 严格模式默认阈值下，所有非零alpha内容被保留，源帧内复制像素的RGBA值不变；所有帧共用同一平移量，不做逐帧居中。
5. 输出各格为同尺寸正方形，行列数、格子顺序及空帧占位保持不变。
6. 中心选项开启时中心严格一致；宽高不同奇偶的原帧在严格模式下得到明确提示。
7. 重采样处理非整除样例时保持几何尺度；用同步播放和逐帧比较核验位置连续性、半透明边缘及无邻格污染。
8. 阈值、留边、网格和模式修改后，预览与导出一致；实际结果以当前参数为准。
9. 验证递归目录结构、重名加序号、输入输出路径限制，以及坏文件、全透明帧/图、贴边内容等异常；不改变源文件。
