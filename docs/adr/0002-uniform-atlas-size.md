# ADR 0002：合成图集后的统一尺寸模式

- 状态：Accepted
- 确认日期：2026-10-16，Asia/Shanghai
- 来源：用户通过 grill-me 确认规则，并授权实现和更新 EXE。
- 本条替代 ADR 0001 中关于输出不缩放、总尺寸必须整除网格的约定；未启用本模式时继续沿用原行为。

## 已确认规则

- 增加默认关闭的“统一尺寸”开关；最大宽度、最大高度分别设置，默认 1024×1024。
- 先按原算法对所有帧统一裁剪，保持原网格和帧序，重新合成一张图集；随后对整张图集等比缩放。
- 超限图片缩小，小图也放大，使整张图集尽量贴合目标范围。至少一边精确达到设置值，另一边按比例取最近的整数像素，最少为 1 像素。
- 不为了统一尺寸补透明外边，不为网格整除修改最终尺寸，不先把每帧缩放成整数边长再拼图。
- 设置 1024×1024 时，2048×1024 和 512×256 均输出 1024×512；5×5 正方形图集精确输出 1024×1024，不改为 1020×1020。
- 提供“平滑／像素”缩放方式，默认平滑。平滑处理透明度，像素方式使用最近邻。
- 统一尺寸与原有严格／重采样裁剪选项独立；启用统一尺寸不会解除严格模式对源网格的校验。
- 预览与导出使用同一个最终图集；按连续的等分网格预览，不将每格起点独立取整或重新居中。图集的逻辑帧宽高可以为小数。
- 原图不修改，仍导出 RGBA PNG，沿用现有重名加序号、逐图错误隔离和处理清单。

## 尺寸与报告

由合成图集宽高与目标宽高的比例确定受限边，受限边精确取目标值；另一边按同一比例四舍五入到整数像素。因此非受限边最多有半个像素的尺寸舍入误差。

裁剪坐标、留边和裁剪帧边长仍以缩放前的像素记录。处理清单同时记录最终逻辑帧尺寸及实际横纵缩放比例，避免将裁剪坐标误认为最终像素坐标。最终输出仍受原有 6400 万像素限制。

## 验收

1. 关闭模式时，既有尺寸、解码像素及错误处理保持一致。
2. 验证放大、缩小、非正方形目标、5×5 非整数格宽、像素方式以及半透明边缘。
3. 最终解码图像与对完整合成图集实施对应缩放的结果一致，无额外透明画布。
4. 预览来自实际最终图集，参数修改会刷新；导出清单与实际 PNG 尺寸一致。
5. 新 EXE 完成窗口操作、预览、导出和真实素材验证，原素材哈希不变。
